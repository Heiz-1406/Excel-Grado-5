¿Qué es Excel?

Microsoft Excel es un programa de hoja de cálculo. Permite organizar información, crear tablas y gráficos y realizar operaciones como sumas, restas, multiplicaciones y divisiones.

Fila: horizontal y se identifica con números.
Columna: vertical y se identifica con letras.
Celda: unión de una fila y una columna.
Ejemplo: B3 significa columna B, fila 3.
ABC
11058
27123
34B39

🖱️ Punteros

➕ Cruz blanca: seleccionar celdas.
✥ Cruz negra: copiar o continuar datos.
↔️ Flecha doble: cambiar ancho de columna.
